# Suporte

Para duvidas de uso e manutencao, abra uma GitHub Discussion ou uma issue usando o formulario apropriado. Antes, pesquise itens existentes e informe versao, ambiente, comportamento esperado, comportamento observado e passos minimos para reproducao.

Falhas de seguranca nao devem ser publicadas: siga [SECURITY.md](SECURITY.md). Este projeto comunitario nao oferece SLA; incidentes de producao devem seguir o [runbook](docs/RUNBOOK.md).
